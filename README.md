# Oxyative Premium Web Launch

Build a premium, modern, conversion-focused website for a new Indian packaged drinking water brand called OXYTIVE.

The website must NOT look like a generic local water supplier website. It should look like a professionally funded FMCG/water brand that is ready to compete with established brands, while still feeling fresh, modern and trustworthy.

PRIMARY GOAL

The #1 objective of this website is LEAD GENERATION.

Every major section should guide visitors toward one of these actions:

Order / Enquire Now

Get a Quote

Become a Distributor

Bulk Order

Corporate / Event Enquiry

Contact on WhatsApp

Call Now

Request a Callback

Do NOT make the website only informational.

Design the entire UX around converting visitors into customers, retailers, distributors, hotels/restaurants, event organizers and corporate buyers.

BRAND

Brand name: OXYTIVE

Category: Packaged Drinking Water

Positioning:
Premium • Pure • Modern • Reliable • Refreshing

The brand is NEW, so do not make fake claims such as:

"India's No.1"

"Most trusted"

"50 years of experience"

fake customer counts

fake certifications

fake reviews

fake distribution numbers

fake awards

fake statistics

Only display certifications, quality claims, manufacturing claims and numbers when actual information is provided.

Instead, create strong trust through professional design, transparent information, quality-focused messaging and enquiry options.
